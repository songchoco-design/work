# Songi Lee 포트폴리오 — GitHub 업로드 안내

## 처음 한 번만
1. github.com 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름 입력 (예: `portfolio`, 또는 `아이디.github.io`로 하면 주소가 `https://아이디.github.io`가 됨) → **Public** → **Create repository**
3. **uploading an existing file** 링크 클릭 → 받은 `index.html`과 이 `README.md`를 끌어다 놓기 → **Commit changes**
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → **Save**
5. 1~2분 뒤 같은 화면 상단에 표시되는 주소로 접속

## 수정할 때마다
1. Claude에서 사이트 수정 → "index.html 다시 만들어줘" 요청 → 다운로드
2. 저장소에서 **Add file → Upload files** → 새 `index.html` 끌어다 놓기 (같은 이름이라 자동으로 덮어씀)
3. 커밋 메시지에 변경 내용 한 줄 (예: "Work에 핀테크 프로젝트 추가") → **Commit changes**
4. 1~2분 뒤 사이트에 반영. 이전 버전은 **History**에서 언제든 확인·복구 가능
